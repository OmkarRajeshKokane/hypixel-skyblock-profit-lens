NPC → NPC guide

Check fixed-price NPC shop routes

This page compares a purchase from one NPC shop with a sale to an NPC. Both prices are fixed reference values, so a route is only shown when the listed sale value is higher than the listed purchase cost. Unlike Bazaar routes, there is no Bazaar tax and no player-order price movement in this calculation.

NPC-to-NPC opportunities are uncommon because shop buy prices are generally higher than NPC sell prices. Seeing “No profitable trade available” is a useful result: it means the current reference data does not support an immediate fixed-price profit route, rather than that the page has failed to load.

When a route is available, available coins and inventory slots still control the maximum suggested quantity. NPC purchase limits can also apply, so check the actual shop screen before buying. The game can change shop inventories and prices; this website is an independent reference and is not an official Hypixel source.

What to verify

  • Identify the actual buying and selling NPC in game.
  • Check the shop price and sell value shown in the confirmation screen.
  • Respect any daily purchase limit before using the maximum quantity.
